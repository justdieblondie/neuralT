# Instrukcje pracy w tym projekcie

1. Nigdy nie kompiluj projektu, chyba że użytkownik wyraźnie o to poprosi.
2. Nigdy nie uruchamiaj testów ani nie twórz nowych testów, chyba że użytkownik wyraźnie o to poprosi.
3. Przed wprowadzeniem jakichkolwiek zmian najpierw podsumuj planowane zmiany i poczekaj na wyraźne potwierdzenie użytkownika. Nie edytuj plików przed otrzymaniem tego potwierdzenia.
